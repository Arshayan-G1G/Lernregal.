# Lernregal

Lernmodule nach Fach sortiert. Läuft auf GitHub Pages, ohne Anmeldung.

## Neues Modul hinzufügen

1. Die HTML-Datei des Moduls in den Ordner `module` hochladen (Name ohne Leerzeichen und Umlaute, z.B. `chemie-atome.html`).
2. `index.html` öffnen, auf den Stift (Bearbeiten) klicken und oben in der Liste `MODULE` eine Zeile ergänzen:

```js
 {fach:"Chemie",titel:"Atombau",text:"Kurz, was drin ist.",tags:["Zusammenfassung"],datum:"2026-10-20",datei:"module/chemie-atome.html"},
```

3. «Commit changes» klicken. Nach 1–2 Minuten ist das Modul online.

Mögliche Fächer: Biologie, Chemie, Geschichte, Französisch, Englisch, Deutsch, Mathematik, Informatik, Geografie.
